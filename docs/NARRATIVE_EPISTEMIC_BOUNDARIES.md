# Narrative epistemic boundaries

The Human Metadata Narrative is a bounded symbolic reflection. Stable
calculation does not make traditional interpretation a scientific personality
measurement.

## Evidence hierarchy

1. `deterministic_calculation` — returned arithmetic, string measures, and
   astronomical positions.
2. `deterministic_relationship` — returned aspects, complete channels, defined
   centers, gates, and other versioned structural relationships.
3. `traditional_symbolic_interpretation` — ontology mappings attached to named
   conventions.
4. `user_supplied` — optional psychology/context, clearly labeled and not
   independently verified.
5. `interpretive_synthesis` — motifs, gifts, possible shadows, tensions, and
   developmental questions authored by deterministic project templates.

The hierarchy is categorical, not a ladder that converts Tier 1 calculation
into Tier 5 truth. Direct behavioral evidence, if added under an approved future
contract, must outrank symbolic recurrence.

## Language rules

Allowed language includes “may,” “favors,” “symbolizes,” “emphasizes,” and
“reflection question.” Claims of destiny, invariability, proof, diagnosis,
guaranteed outcomes, supernatural certainty, or exact future events are blocked.
Every possible shadow is paired with the source gift and described without
shaming or clinical inference.

The prohibited topics include medical and psychiatric conclusions, trauma or
abuse history, addiction, criminality, violence, sexuality, gender identity,
fertility, pregnancy, death, lifespan, legal outcomes, financial destiny,
political ideology, religious truth, spiritual rank, supernatural powers,
guaranteed compatibility, and guaranteed career or relationship outcomes.

## Provenance

`motif-ontology-v1` is a project-authored normalization layer over the existing
returned symbolic conventions. Its records name the source system, source
symbol, normalized motifs, strength, notes, and mapping version. The project
does not present those normalization choices as quotations from fabricated
authorities. Exact system source IDs continue to come from existing encoder
provenance envelopes.

## What a sentence does not prove

A linked sentence proves only that the deterministic plan used the displayed
returned values and declared ontology rules. It does not prove that the motif
describes the subject, that systems validate one another, or that an outcome
will occur. User observation and validated assessment remain the appropriate
ways to test a reflection against lived reality.
